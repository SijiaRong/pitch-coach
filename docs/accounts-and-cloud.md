# 微信登录与云端保存

公开报告、教练名单和固定示例无需登录。本机报告可在当前设备继续使用。跨设备保存、购买与送礼需要微信身份；不会要求手机号、头像、通讯录或位置权限。

## 用户操作

“我的”页提供“微信登录并开启云端保存”。用户主动选择后，后台记录云端保存同意，新完成的真实评估会加密保存，并归属当前微信身份。同一小程序 AppID 下，同一微信用户重新登录或更换设备，会访问相同账户。OpenID、session_key、AppSecret 不返回客户端。

昵称和角色可选，不从微信自动抓取；角色为本人声明。云端保存默认关闭。关闭自动保存不会删除已有报告；云端报告与本机副本可分别删除。清空本机不会停止公开分享，公开项目需单独管理。退出只清除当前设备会话，本机报告仍保留。

云端最多 100 份，不会自动淘汰旧报告。重复同步同一份报告不会重复计数。只同步用户本人的带后台签发凭证的真实评估；固定示例留在本机，缺凭证的旧报告不会被当作已核验报告导入。

## 后台配置

`CLOUD_STORAGE_ENABLED=false` 为默认值。需要启用时，在后台私有环境设置：

```dotenv
CLOUD_STORAGE_ENABLED=true
PROJECT_DATABASE_PATH=/var/lib/pitchcoach/projects.sqlite
PROJECT_DATA_KEY=<64位十六进制稳定随机密钥>
OWNER_ID_SECRET=<至少32字符的稳定身份密钥>
SESSION_SECRET=<至少32字符的会话签名密钥>
WECHAT_APP_ID=<当前小程序AppID>
WECHAT_APP_SECRET=<服务端AppSecret>
```

可以只开云端保存，保持 `PROJECT_SHARING_ENABLED=false`、`VIRTUALPAY_ENABLED=false`。云端报告不会自动公开。生产数据库必须使用发布目录之外的绝对路径与持久卷；该目录需位于部署服务允许写入的位置。数据库与加密密钥分开备份，不能放静态网站目录或提交 Git。

**已有微信评估订单的部署升级时**，首次引入 `OWNER_ID_SECRET` 应沿用此前生成用户标识所使用的稳定 `SESSION_SECRET` 值，以保留原有订单/额度归属；不要为身份密钥随意换值。随后会话签名可以独立轮换，稳定身份密钥仍保持不变。不要把实际密钥发到聊天或文档中。

报告、昵称使用 AES-256-GCM 加密，并绑定所属用户和报告编号，数据库重启后可恢复。当前为单进程 SQLite，不能直接挂到多个独立写入实例；备份时使用 SQLite 一致性备份，或停止该服务后同时按实际数据库状态备份，不要在写入时只复制主文件而遗漏 WAL。现有支付账本维护脚本只管理评估支付账本，不会自动备份这个新数据库。

## 接口

- `GET /api/account/config`：公开查询微信登录和云端存储可用性。
- `GET /api/me`：本人账户、昵称、角色、同步设置和云端报告数量。
- `POST /api/me`：修改本人昵称、角色或云端设置；首次开启需 `cloudStorageConsent=true`，服务端保存同意版本与时间。
- `GET /api/me/reports`：本人报告摘要列表。
- `GET /api/me/reports/:id`：本人完整报告，其他身份或不存在均返回 404。
- `POST /api/me/reports`：主动同步本人已签发的真实报告；验证归属、内容签名与有效期。
- `DELETE /api/me/reports/:id`：删除本人的云端副本，不影响公开项目、订单和本机副本。

这些接口要求真实微信会话；开发匿名会话不能假装微信绑定。客户端保存的登录标记只用于显示，权限始终由服务端签名会话与报告归属检查决定。会话过期需重新登录，账户和记录不会因 token 过期而删除。

真实评审、资料解锁、送礼使用同一套内部微信用户标识，但订单和云端保存是独立功能。云端保存失败不会把已完成评估改为失败、自动追加收费或删除本机报告。报告页会区分“已保存”“仅本机”和“暂无法确认”；用户可主动重试。

## 礼物与两类支付

围观者通过礼物目录选择火花（8.88 元）、助推器（88.88 元）、火箭（888.88 元）、星舰（8888.88 元）。确认页显示实际金额，礼物为数字展示，不对应实物、股权或回报。动效仅在演示完成或服务端核实付款后触发。

新增订单使用 `kind=gift`、`giftId`，名称、金额由后台目录绑定并快照保存。客户端不能把火箭改成火花价格。旧 `tip` 订单继续可查询，不修改既有记录；旧商品映射 `tip:金额` 兼容读取，新配置使用 `gift:金额`。

评估支付沿用主分支 JSAPI 账本与 JSON 回调 `/api/payments/wechat/notify`。资料访问与礼物的虚拟支付使用 XML 安全模式回调 `/api/payments/virtual/notify`，两者分别配置，避免回调路径和协议冲突。5% 服务费仍按退款后的已核实实收逐笔计算；没有自动提现或转账功能。

## 验证边界

本地测试使用替身微信与虚构资料，覆盖同一微信重复登录、用户隔离、独立同意、加密持久化、重启恢复、关闭同步、删除、幂等和保存失败。H5 可以看示例和本机报告；真实微信登录、跨真机同步及付款仍需部署者的 AppID、AppSecret、HTTPS 后台与实际账户联调。
