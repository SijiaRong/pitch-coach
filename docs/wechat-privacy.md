# 微信隐私配置与上线核对

本次页面面向上海动御新媒体科技有限公司运营、使用 DeepSeek 官方 API 的微信小程序。隐私联系邮箱为 support@actionandlink.com。源码内置这两项公开信息；更换实际运营主体时，在小程序构建环境中设置 `VITE_OPERATOR_NAME`、`VITE_PRIVACY_CONTACT_EMAIL`，同步修改微信后台资料并重新构建。

## 小程序内已有的告知和选择

- 首页的“关于”、提交页、我的报告均可进入“隐私与使用说明”。页面包含信息类别、用途、接收方、保存范围、用户权利、联系渠道和使用须知。
- 不在启动时弹出自定义隐私窗口，不为浏览示例申请文件或相册权限。微信隐私接口沿用官方按需授权弹窗，不注册覆盖式的自定义 `onNeedPrivacyAuthorization` 监听。
- “选择并上传 BP”旁说明上传用途；上传只在后台提取文字，不自动调用模型。用户可以检查和精简提取文字。拒绝文件权限仍可粘贴脱敏文字。
- 真实评估前单独勾选“将项目资料发送给 DeepSeek”。首次不默认勾选；同意记录包含说明版本、运营主体、接收方和时间，仅存本机。版本、运营主体或接收方变化时需重新同意。
- 隐私管理中可撤回该选择。返回提交页会刷新状态；登录等待期间撤回，也不会继续发送项目资料。若设备存储不可用，仅在本次使用中保留明确选择，并提示撤回状态的持久化限制。
- 报告可逐份删除或清空。清理本机记录不会删除模型方可能保存的数据，也不会删除已保存至相册或自行分享的海报。
- “我的”页可主动微信登录并开启云端保存。完整报告与可选昵称加密保存，按微信身份隔离；本机和云端副本分别删除。关闭自动保存不删除已有云端报告，退出登录仍保留本机报告。公开分享、资料解锁与礼物留联分别确认，不隐含在登录或云端保存同意中。
- 真实报告、复制的改进清单和导出海报均有“AI 生成”标识；虚构示例单独标明演示。

## 微信公众平台仍需配置的内容

页面和代码不能代替账号后台申报。使用小程序管理员账号进入“设置 → 服务内容声明 → 用户隐私保护指引”（入口名称以实际后台为准），按最终部署逐项填写：

1. 运营主体：上海动御新媒体科技有限公司；隐私联系邮箱：support@actionandlink.com。保持与实际小程序主体一致。
2. 说明微信登录标识用于会话归属、报告隔离、订单关联与次数限制；项目介绍和可选 BP 用于解析与评估；主动开启云端保存后，评估报告、可选昵称及本人声明的角色用于项目档案与跨设备查看。必要网络信息用于服务与安全。不要勾选“未采集隐私”。
3. 对照微信当前的接口与信息类型映射，声明 `chooseMessageFile` 对应的“收集你选中的文件”、`saveImageToPhotosAlbum` 对应的“使用你的相册（仅写入）权限”。微信也将 `setClipboardData` 列在剪贴板信息类型下，须按平台映射申报，并如实说明仅在用户点击复制时写入所选内容，不主动读取原有剪贴板。只申请实际使用的项，不申请读取整本相册、通讯录、定位、麦克风、相机或调用 `getClipboardData`。相册保存只在用户点击保存时触发。
4. 在第三方处理相关字段中披露 DeepSeek：杭州深度求索人工智能基础技术研究有限公司；目的为文本项目评估；信息为项目资料和评审设置。提供其隐私政策及 privacy@deepseek.com 联系方式。按实际 API 合作协议确定处理关系、保存期限与用途，不直接套用第三方自己的用户隐私政策作为本应用政策。
5. 按实际部署补充境内云服务提供方、委托处理、安全日志的具体保存期限和必要的申诉/投诉处理流程。未主动开启云端保存或公开分享的普通评估不持久保存 BP；开启云端后会保存包含评审依据与摘录的完整报告，见[账户与云端说明](accounts-and-cloud.md)。可选公开分享会持久保存用户确认的报告、资料正文、联系方式、订单及微信身份关联，私密内容加密。还需如实说明微信支付接收方、披露范围、履约、退款、保存期限、项目方停止公开和后台信息请求的流程，见[分享与支付说明](project-sharing.md)。网关、备份、监控及模型方实际行为必须与公示相符。不要开启请求正文、认证头或模型完整响应的日志记录。
6. 发布微信平台隐私保护指引，在真机确认“微信平台隐私保护指引”按钮能够打开。若后台未声明相关信息类型，对应接口仍可能被微信禁用。

已有同主体认证公众号时，可确认后台是否支持复用认证资质；小程序备案、AI 类目、隐私申报及代码审核仍分别办理。

## DeepSeek 与 AI 服务材料

当前文案仅适用于 DeepSeek 官方 API。若以后替换供应商、添加按角色调用其他模型、调整个人信息处理目的或范围，应同时更新 `apps/miniprogram/src/lib/privacy.ts` 的接收方信息和 `PRIVACY_VERSION`、页面告知、后台隐私指引及相应合作材料，重新取得相应同意。不能只改后台模型地址。

按实际功能核定“深度合成 / AI 问答或 AI 创作”等类目，准备模型技术方算法备案材料及合作协议；向属地网信部门确认 AI 应用登记事项。DeepSeek 提供合作协议申请工单，详见其官方 FAQ。取得材料后再补充真实模型备案号或上线编号；不要在界面填入未经核实的编号。

本次增加显式“AI 生成”文字，不能替代对实际发布场景下完整显式/隐式标识义务的确认。

## 真机验收

- 新用户可直接浏览首页、教练和示例；启动不弹出自定义隐私窗口。
- 首次真实评估前，AI 资料处理默认未同意；未同意时不得提交项目资料。主动同意后重新进入提交页不重复勾选。
- 从已填写的提交页查看隐私说明后返回，内容和评审设置保持；从隐私管理撤回后返回，勾选恢复为未同意。
- 首次选择文件出现微信官方授权，拒绝不上传且不触发 AI；普通取消选文件没有错误弹窗。允许后可提取正文、检查并修改。
- 保存图片只在点击保存时请求对应授权；拒绝后仍能预览或分享，不能暗中保存。
- 真机打开平台隐私指引；从反馈入口可提交隐私问题，联系邮箱可复制。
- 删除/清空报告后重新打开仍不显示；清空不会更改 AI 同意状态。核查真实海报和复制文本仍保留 AI 标识。
- 使用当前实际 DeepSeek 模型实测生成、取消和失败流程，确认日志、网关及模型合作约定与公示一致。
